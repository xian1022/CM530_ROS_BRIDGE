# HOME 姿態校正資料收集（Windows）

## 目標與本次範圍

以手動擺出的姿態為基準，最終設定 **arm1 的 home_A 右轉 30°、arm2 的 home_C 左轉 30°**。左右以各手臂自身朝向為準，不以拍照者或畫面左右為準。兩臂皆須鏡頭朝下，光軸垂直桌面、成像平面與桌面平行。

本次只收集基準姿態、底座方向與平行度資料，不修改 HOME、不重建或燒錄韌體，也不自動驅動手臂完成 30° 轉動。照片是手動擺出的姿態，不能假設等於程式內的 HOME。

`READ` 回傳的是馬達原始位置整數（0～1023），**不是角度**；0～1023 也不代表機構全範圍都能安全活動。未完成零點、方向與安裝角校正前，不直接由照片猜四軸數值。

| 手臂 | 預設名稱 | j1 / j2 / j3 / j4 馬達 ID | 最終轉向 |
|---|---|---|---|
| arm1 | home_A | 17 / 3 / 2 / 15 | 自身右轉 30° |
| arm2 | home_C | 12 / 1 / 8 / 16 | 自身左轉 30° |

j1～j4 目前暫定由下到上；本次需觀察 j1 是否確實對應底座轉動。

## 1. 另一台電腦的準備

1. 複製整個 `17 ROS to CM530 ver. dual arm` 資料夾到 Windows 電腦。
2. 安裝 Python 3，確認 PowerShell 可執行 `python --version`。若使用 `py` 啟動器，以下所有 `python` 可一致替換成 `py -3`。
3. 關閉會占用序列埠的 ROS 節點、RoboPlus 與其他終端。
4. 連接控制板，在 Windows「裝置管理員 → 連接埠（COM 和 LPT）」查找實際 COM 埠。
5. 在第 17 版資料夾內開啟 PowerShell，執行：

```powershell
python -m pip install -r requirements.txt
python manual_position_terminal.py --port COM4 --baud 57600
```

將 `COM4` 替換成實際埠。若找不到腳本或 requirements.txt，先確認目前所在資料夾。終端啟動時會顯示說明並自動送一次 PING。

後續命令輸入在程式的 `arm1/arm2>` 提示符號後，**不是 PowerShell**。每次只送一筆，收到完整成功回覆後再送下一筆，不整段一次貼入。

本測試不使用 `demo`、`HOME`、`AX`、`HOLD` 或 `TORQUE,...,1`。其中 `GET_HOME` 是唯讀查詢，與會寫入目標的 `HOME` 不同。

## 2. 確認連線與板上設定

逐筆輸入：

| 輸入命令 | 預期回覆 |
|---|---|
| `PING` | `PONG` |
| `VERSION` | `VERSION,5` |
| `GET_HOME,arm1` | `HOME,arm1,j1,j2,j3,j4` |
| `GET_HOME,arm2` | `HOME,arm2,j1,j2,j3,j4` |

表格中的 j1～j4 代表實際回覆的四個整數，不是要輸入的文字。記錄兩筆完整 HOME 回覆，不假設控制板已燒錄目前工作區的韌體。若版本不是 5，停止本流程並記錄回覆。

**任何步驟出現 ERR、逾時、回覆不符或 Session stopped，保留完整輸入與輸出並停止該步驟。** 不以猜測數值或繼續送命令代替確認。

## 3. 卸力並記錄手動基準姿態

每次只處理一臂。卸力後手臂可能因重力下垂，先支撐手臂與末端，再操作；不要硬扳仍在施力的關節。

### arm1

1. 支撐 arm1，確認可安全手動調整。
2. 輸入 `TORQUE,arm1,0`，等候 `OK,TORQUE,arm1,0`。若仍有明顯施力或阻力，不強行轉動，停止並記錄。
3. 手動擺到照片所示的預期基準姿態，使鏡頭朝下。記錄此時底座朝向作為稍後比較的基準。
4. 維持姿態，輸入 `READ,arm1`。
5. 記錄完整 `POS,arm1,j1,j2,j3,j4`，標為「arm1 基準 READ」。

### arm2

1. 先確保 arm1 已有穩固支撐，再支撐 arm2。
2. 輸入 `TORQUE,arm2,0`，等候 `OK,TORQUE,arm2,0`；若仍有施力或阻力，停止。
3. 手動擺到預期基準姿態，使鏡頭朝下，記錄底座朝向。
4. 維持姿態，輸入 `READ,arm2`。
5. 記錄完整 `POS,arm2,j1,j2,j3,j4`，標為「arm2 基準 READ」。

READ 是依序讀取四顆馬達，讀取期間應維持手臂不動。不要把 GET_HOME 的設定值填入基準 READ 欄位。

## 4. 確認底座數值增加的方向

本步驟兩臂都以「自身右轉」作為方向探測，方便比較；**arm2 最終目標仍是左轉 30°**。

1. 保持待測手臂卸力且有支撐，另一臂穩固放置。
2. 從該臂剛才的基準朝向，只將底座朝手臂自身右方小幅轉動，在可自由活動範圍內操作，不碰機構限位。維持其他關節姿態。
3. arm1 輸入 `READ,arm1`；arm2 輸入 `READ,arm2`。各自記錄完整「右轉後 READ」。
4. 比較同一臂的基準與右轉後 j1：

| 比較結果 | 可以記錄的結論 |
|---|---|
| 右轉後 j1 大於基準 j1 | 此臂自身右轉時原始值增加 |
| 右轉後 j1 小於基準 j1 | 此臂自身右轉時原始值減少 |
| j1 不變、讀值不穩或其他軸明顯變動 | 尚無法確認；記錄情況，不推定方向 |

5. 核對 j2～j4 是否保持不變或只有微小讀值差異；若手動操作帶動其他關節，重新擺回基準後再量測，保留異常紀錄。
6. 測完一臂，手動回復基準朝向並穩固支撐，再測另一臂。可再次 READ 記錄回復後數值。

這只是方向確認，**不代表已完成或量得 30°**。若 j1 沒有隨底座變動，停止套用上述方向結論，先核對關節與 ID 對應。

## 5. 量測相機與桌面平行度

在回復基準姿態後，分別量測兩臂：

1. 以桌面作為參考面，用數位傾角計或合適量角工具比較相機固定板與桌面的夾角。
2. 量測兩個互相垂直的方向，例如沿手臂前後、左右方向；記錄相對桌面的偏差、傾斜方向及工具解析度。不要只量一個方向。
3. 確認鏡頭朝下。固定板量測僅在固定板與相機成像平面平行時能代表成像平面的方向；若安裝關係不確定，標示「尚未確認」，不能直接宣稱成像平面已平行。
4. 記錄照片或量測說明作為輔助，不能只用照片判定精確平行。

若為了調平改變了關節姿態，重新執行該臂 READ 並標明「調平後基準」；不要把調平前、後資料混在一起。方向比較的前後 READ 必須來自同一組基準。

## 6. 結束

確認兩臂都有穩固支撐，再於終端輸入：

```text
q
```

`q` 只退出終端，**不會自動改變 torque 狀態**。本流程成功卸力後未重新啟用施力，不要預期退出時手臂會自行保持姿態。若流程中斷或命令失敗，不能由退出推定馬達已卸力。
