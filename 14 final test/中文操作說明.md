# CM-530 Final Test 正式 ROS 版中文操作說明

本資料夾 `14 final test` 是準備交給 ROS 端使用的正式版韌體。

重點：

- ROS 端負責 IK 與 rad -> AX position 整數轉換。
- CM-530 只接收 AX position 整數，不做浮點、不做 IK。
- 正式韌體只輸出規格書 ACK / ERR，不輸出回顯、`ALIVE`、`[TARGET]`、`[ACTUAL]`。

## 1. 要燒錄的韌體

用 RoboPlus Terminal 燒錄：

```text
C:\Users\39165\Downloads\CM530_ROS_BRIDGE\14 final test\CM530.hex
```

燒錄完成後請關閉 RoboPlus / RoboPlus Terminal，避免占用 `COM4`。

注意：正式版開機後可能完全不主動輸出文字。這是正常的，請用 `PING` 確認 app 是否有跑。

## 2. Serial 規格

```text
Port      : COM4
Baud Rate : 57600
Data Bits : 8
Parity    : None
Stop Bits : 1
Format    : ASCII
Line End  : \n
```

## 3. 關節順序

```text
j1 -> ID17
j2 -> ID3
j3 -> ID2
j4 -> ID7
```

所有位置都是 AX-12A 整數 position：

```text
0..1023
```

## 4. 正式指令

ROS 端只能依規格書使用：

```text
PING
BEGIN,<traj_id>,4,<point_count>
PT,<seq>,<dt_ms>,<j1_pos>,<j2_pos>,<j3_pos>,<j4_pos>
END,<traj_id>
STOP
HOME
```

正式版不使用舊測試用的 `AX`、`Q`、`C`、`ALIVE`。

## 5. ACK 格式

```text
PONG
OK,BEGIN,<id>
OK,PT,<seq>
OK,END,<id>
OK,STOP
OK,HOME
ERR,<code>
```

ROS 端應該逐筆傳送並等待 ACK：

```text
ROS -> PT
CM  -> OK,PT,<seq>
ROS -> 下一筆 PT
```

禁止一次送整條軌跡。

## 6. PowerShell 正式協定測試

關閉 RoboPlus 後執行：

```powershell
cd "C:\Users\39165\Downloads\CM530_ROS_BRIDGE\14 final test"
python .\cm530_bridge_smoke_test.py --port COM4 --baud 57600
```

此測試會只用正式協定：

```text
PING
STOP
HOME
BEGIN,1,4,3
PT,0,300,512,512,512,512
PT,1,400,520,512,512,512
PT,2,400,512,512,512,512
END,1
STOP
```

這是一個小幅安全動作測試：j1 從 512 小移到 520，再回 512。

如果第一次 `PING` 沒反應，工具會提示你按 CM-530 RESET / 重新上電，然後嘗試送 bootloader `-GO`。

## 7. RoboPlus Terminal 手動測試

正式版沒有 `ALIVE`。進 app 後可以手動輸入：

```text
PING
```

預期：

```text
PONG
```

測試小軌跡：

```text
BEGIN,1,4,3
PT,0,300,512,512,512,512
PT,1,400,520,512,512,512
PT,2,400,512,512,512,512
END,1
STOP
```

## 8. 常見狀況

### COM4 存取被拒

代表 COM4 被其他程式占用。請關閉：

```text
RoboPlus
RoboPlus Terminal
其他 PowerShell 測試視窗
其他 serial monitor
```

### PING 沒有 PONG

可能還在 bootloader。請用測試工具依提示按 RESET，讓工具送 `-GO`。

### BEGIN 或 HOME 回 ERR

多半是 DXL bus / 電源 / 馬達 ID / torque enable 問題。正式版會回 `ERR,<code>`，ROS 端應停止後續軌跡。
